# Next.js Markdown Blog Starter

This is a lightweight, high-performance blog built with **Next.js 14**, **Tailwind CSS**, and **Markdown (gray-matter & remark)**.

## Getting Started

1. Extract the ZIP file.
2. Open terminal in the project directory.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Adding New Posts

Simply add a new `.md` file inside the `posts/` folder with frontmatter like this:

```markdown
---
title: "Your Post Title"
date: "YYYY-MM-DD"
description: "Short description"
---

Your content in Markdown here...
```
